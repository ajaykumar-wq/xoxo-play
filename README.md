# XOXO - play in the browser

Test build of **XOXO**, IICT's comic tic-tac-toe game with Moku the mole (version 1.8.0).

Play: https://ajaykumar-wq.github.io/xoxo-play/

Levels against Moku: Easy is Classic 3x3, Medium is Tunnel Twist (3x3 with slides and tool cards),
Hard is Gem Mine (6x6, turn a quarter after each move, five in a row wins). Pass & Play can use any of the three.
This repository only holds the built web game.
