# XOXO - play in the browser

Test build of **XOXO**, IICT's comic tic-tac-toe game with Moku the mole (version 1.7.0).

Play: https://ajaykumar-wq.github.io/xoxo-play/

Modes: Gem Mine (6x6, turn a quarter after each move, five in a row wins), Tunnel Twist (3x3 with slides) and Classic.
This repository only holds the built web game.
